# 🌱 About MindMate

**MindMate** is an AI-powered wellness companion designed especially for students.

The application provides a digital space where users can:

✨ Track their daily emotions  
✨ Maintain mood history  
✨ Chat with an AI wellness assistant  
✨ Practice breathing exercises  
✨ Receive personalized self-care suggestions  


The goal of MindMate is to encourage emotional awareness and promote healthier mental habits among students.

# ⚡ Installation


## Clone Repository


```bash
git clone https://github.com/TanushriSV/MindMate.git
```


Move into project:

```bash
cd MindMate
```


---

# 🌐 Run Web Application


```bash
cd MindMate-main
```


Install packages:

```bash
npm install
```


Start application:

```bash
npm run dev
```


Open:

```
http://localhost:5173
```


---

# 📱 Build Android Application


Navigate:

```bash
cd MindMate-Android
```


Build APK:

```bash
./gradlew assembleDebug
```


APK Location:

```
app/build/outputs/apk/debug/app-debug.apk
```
